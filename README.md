# 窗口标签

Windows 10/11 桌面工具。给 UE、Maya 等应用的每个窗口贴上独立的文字和颜色标签，适合区分双开的账号、环境或项目。

1. 下载 [WindowLabels-v2.exe](./WindowLabels-v2.exe)，双击运行。如果旧版正在运行，先从系统托盘退出旧版。
2. 在列表中选择目标窗口（例如 Unreal Editor），或按住「拖到目标窗口」按钮，拖到要标记的窗口上再松开。也可以切到目标窗口后按面板右上角显示的全局快捷键。
3. 输入「主账号」，选择颜色，点「贴上并查看」。工具会切回目标窗口。再为第二个窗口贴上「测试号」。文字留空时，工具会自动使用「窗口 A」「窗口 B」等名称。

标签随窗口移动和缩放。鼠标可以穿过标签操作原应用。首选位置被盖住时会尝试其余角落。窗口最小化或四个角落都无法显示时，标签会隐藏，面板会显示原因。可以在管理面板或系统托盘暂停、恢复全部标签。

默认快捷键是 `Ctrl + Alt + T`。若已被占用，程序会依次尝试 `Ctrl + Alt + Shift + T` 和 `Ctrl + Shift + F9`。从列表或拖动按钮选窗时无需快捷键。

关闭面板后标签继续显示。双击系统托盘图标重新打开面板，右键托盘图标可以退出工具。标签绑定当前窗口实例，关闭并重新打开目标窗口后需要重新贴标签。若目标应用以管理员身份运行，请用相同权限启动本工具。

在此目录运行 `./Build.ps1` 可用 Windows 自带的 .NET Framework C# 编译器重新生成程序。
